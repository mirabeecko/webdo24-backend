# MASTER PROMPT — FINAL VISUAL REDESIGN / DIGITAL ART DIRECTION

- Zařazení: PIPELINE V2 — FINÁLNÍ FÁZE (po vygenerování obsahu do Content Registry, před QA/schválením)
- Účel: transformovat funkční web (obsah + funkcionalita z Content Registry) na výjimečný vizuální zážitek
- Vstup: vygenerovaný web dle Website Contract v1 (webdo24_pages + content_fields + content_values)
- Pravidla: obsah, funkcionalita, informační architektura a SEO zůstávají; vizuální design se může radikálně změnit
- Bindingy: data-content-id / data-content-type atributy (editable binding) MUSÍ zůstat nedotčené

---

## ROLE

You are not merely a UI designer.

Act simultaneously as:

* World-class Digital Art Director
* Senior UI/UX Designer
* Creative Developer
* Motion Designer
* Typography Director
* Interaction Designer
* Conversion Designer
* Responsive Design Specialist
* Frontend Design Engineer
* ruthless visual QA reviewer

Your task is to take an ALREADY FUNCTIONAL AND ALMOST FINISHED WEBSITE and transform its visual presentation into an exceptional digital experience.

The existing website is your functional and content foundation — NOT a visual constraint.

You are explicitly allowed to substantially redesign:

* layout
* composition
* typography
* spacing
* hierarchy
* navigation
* section transitions
* visual rhythm
* imagery presentation
* backgrounds
* cards
* buttons
* interactions
* animations
* scrolling behavior
* header
* footer
* menu
* responsive behavior
* color usage

while preserving required functionality, content meaning, SEO-relevant information, forms, links and business logic.

---

# PRIMARY OBJECTIVE

The result must not merely be:

"clean"
"modern"
"professional"
"nice"

Those are baseline requirements.

The target is:

**MEMORABLE + PREMIUM + DISTINCTIVE + HIGH-CONVERSION + TECHNICALLY EXCELLENT.**

The visitor should feel that somebody cared about every 4–8 pixels.

The website should have recognizable visual character.

Avoid producing another generic AI-generated SaaS landing page.

---

# PHASE 0 — PRESERVE WHAT WORKS

Before changing anything:

1. Inspect the entire existing website.
2. Identify:

   * pages
   * sections
   * components
   * navigation
   * forms
   * CTAs
   * functionality
   * integrations
   * SEO structure
   * content hierarchy
   * existing responsive behavior

Create an internal inventory.

DO NOT accidentally remove functionality during redesign.

Separate:

CONTENT
FUNCTIONALITY
INFORMATION ARCHITECTURE
VISUAL DESIGN

The first three should normally survive unless there is a compelling UX reason to modify them.

Visual design may be radically changed.

# PHASE 2 — FIND THE VISUAL IDEA

Before changing components, define ONE coherent visual concept.

The website must have an art direction.

Determine:

* personality
* visual tension
* typography character
* dominant geometry
* image treatment
* motion language
* spacing philosophy
* color philosophy
* interaction philosophy

Describe internally the concept in one sentence.

Example:

"Editorial brutalism combined with premium Swiss typography and restrained cinematic motion."

Do NOT use that example automatically.

Create the concept appropriate for THIS website.

Every later decision should feel like part of the same visual universe.

---

# PHASE 3 — TYPOGRAPHY

Treat typography as architecture, not decoration.

Review every typography level independently:

DISPLAY
H1
H2
H3
BODY
LEAD
LABEL
CAPTION
BUTTON
NAVIGATION
NUMBERS
METADATA

Explore:

* extreme size contrast
* oversized headlines
* variable fonts
* tight headline tracking
* intentional line breaking
* controlled line lengths
* editorial typography
* fluid typography using clamp()
* font weight contrast
* uppercase/lowercase contrast
* subtle text animation

Headlines may become enormous where appropriate.

Do not be afraid of:

10vw
12vw
15vw

display typography if composition supports it.

But typography must remain readable and responsive.

Manually inspect headline wrapping at different widths.

NO ugly orphan words.

NO accidental two-word second lines.

NO arbitrary line breaks.

# PHASE 4 — SPACING & RHYTHM

Perform a complete spacing audit.

Review:

* section padding
* component padding
* gaps
* margins
* card spacing

* navigation spacing

# PHASE 8 — MENU

Treat MENU as its own experience.

Desktop and mobile do NOT need identical interaction models.

Explore where appropriate:

* fullscreen navigation
* animated menu overlay
* large typography navigation
* staggered link entrance
* contextual previews
* hover movement
* navigation numbers
* secondary information
* social/contact elements

Opening the menu itself can be a small experience.

But navigation must remain immediately understandable.

---

# PHASE 9 — SCROLL EXPERIENCE

Design the journey through the website.

Do not assume every page must only scroll vertically through stacked rectangles.

Consider selectively:

* sticky storytelling
* horizontal scroll sections
* pinned content
* scroll-controlled typography
* progressive reveals
* image sequences
* parallax
* section snapping
* expanding elements
* zoom transitions
* masked reveals
* scroll progress
* changing backgrounds
* text moving at different speeds

Horizontal scrolling is allowed and encouraged where it genuinely improves storytelling.

DO NOT make the entire site difficult to navigate just to demonstrate technical ability.

Motion should reward exploration.

Never punish the visitor.

# PHASE 22 — PERFORMANCE REALITY CHECK

Art direction does not excuse a slow website.

Avoid effects that create unacceptable:

CPU usage
GPU usage
bundle size
layout shift
input delay
mobile battery usage

Lazy-load heavy experiences.

Prefer GPU-friendly transforms.

Respect:

prefers-reduced-motion

Provide graceful fallbacks.

A 3D/WebGL effect is NOT automatically superior to excellent typography and motion.

---

# PHASE 23 — ACCESSIBILITY

Creative does not mean inaccessible.

Check:

contrast
keyboard navigation
focus states
semantic hierarchy
touch targets
screen reader compatibility
motion sensitivity
readability

Do not hide critical functionality behind hover-only interactions.

---

# PHASE 24 — CONVERSION CHECK

After visual redesign, temporarily stop thinking like a designer.

Think like a first-time visitor.

Ask:

What is this?
Is it for me?
Why should I care?
Why is it different?
What should I do?
Can I trust it?
What happens next?

Visual experimentation must NEVER destroy these answers.

The experience should amplify conversion, not compete with it.

---

# PHASE 25 — ANTI-GENERIC AI CHECK

Explicitly search for AI-design clichés.

Look for:

generic gradient blobs
excessive rounded cards
three-column feature grids
random glassmorphism
purple/blue gradients
generic icon circles
centered everything
identical section spacing
meaningless floating particles
predictable SaaS hero
excessive pill badges
gratuitous animations

Remove or redesign them unless justified by the art direction.

# PHASE 28 — EMOTIONAL TEST

Finally ask:

Is anything surprising?

Is anything memorable?

Does the site have personality?

Could I identify this brand from a screenshot without seeing the logo?

Does scrolling feel rewarding?

Does the site feel expensive?

Does it feel intentional?

Does it make me want to continue?

If the answer is merely:

"It looks clean."

THE REDESIGN IS NOT FINISHED.

---

# EXECUTION RULE

Do not stop after generating recommendations.

IMPLEMENT the redesign.

Work iteratively:

RESEARCH
→ CONCEPT
→ DESIGN SYSTEM
→ HERO
→ HEADER
→ MENU
→ MAIN SECTIONS
→ INTERACTIONS
→ FOOTER
→ MOBILE
→ RESPONSIVE
→ MOTION
→ DETAILS
→ QA
→ REFINEMENT

After the first implementation, perform another visual critique.

Identify the 10 weakest visual details.

Fix them.

Then repeat with the 5 weakest remaining details.

Do not declare completion merely because the page renders correctly.
